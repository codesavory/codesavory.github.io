# Houdini Vellum Ripple Solver

This work shares my Houdini learning experience -- Vellum, Fluids, and Bubbles SOP.

Inspired by [Alexander Eskin Tutorial](https://www.youtube.com/watch?v=ypJL4PXxQpg)
<br/>
1. Vellum Fluids - Using the Vellum Fluids to model ripples on Surfaces
2. Bubbles SOP - Faking bubbles using spheres in SOP and Noise.
3. MaterialX - Modelling Realistic Bubbles using MaterialX Specular and Transmission.
4. Karma - Rendered entirely in Karma
